# ☕ Coffee Shop Sales Dashboard

## 📌 Project Overview
This project is an interactive Coffee Shop Sales Dashboard built using Tableau and Excel. The dashboard analyzes coffee shop performance by tracking revenue, profit, sales quantity, and customer transactions to generate meaningful business insights.

---

## 📊 Key Metrics
- Total Profit: 2,464
- Total Quantity Sold: 2,034
- Total Revenue: 7,039
- Total Transactions: 1,441

---

## 📈 Dashboard Insights
- Category-wise sales and revenue analysis
- Monthly transaction trends
- Revenue distribution across cities
- Weekday transaction performance
- Year-wise revenue comparison
- Identification of top-performing product categories

---

## 🛠️ Tools & Technologies
- Tableau
- Microsoft Excel

## 💡 Skills Demonstrated
- Data Cleaning

## 🎯 Project Outcome
The dashboard helps understand customer purchasing behavior, peak sales periods, and revenue trends across different categories and locations. It supports data-driven business decision-making through interactive visualizations.
